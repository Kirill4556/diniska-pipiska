# splitter

Делит песню на два файла: **минус** (инструментал) и **вокал**. Вся обработка локальная.
Полное ТЗ: [ТЗ приложение-сплиттер mp3 → минус + вокал.md](<ТЗ приложение-сплиттер mp3 → минус + вокал.md>).

## Установка

Нужен [uv](https://docs.astral.sh/uv/). ffmpeg ставить не надо — он идёт вместе с зависимостями.

```
uv sync
```

## Запуск

Окно (перетащите песни или папки, выберите качество и формат, нажмите «Разделить»):

```
uv run splitter-gui
```

Командная строка:

```
uv run splitter song.mp3 --out ./result --format mp3 --bitrate 320 --quality high
uv run splitter ./album --out ./result
```

Результат: `result/song_instrumental.mp3` и `result/song_vocals.mp3`.

| Параметр | Значения | По умолчанию |
| --- | --- | --- |
| `--out` | папка результата | `./result` |
| `--format` | `mp3`, `wav`, `flac` | `mp3` |
| `--bitrate` | `192`, `256`, `320` (только mp3) | `320` |
| `--quality` | `fast` (Demucs htdemucs), `high` (BS-Roformer), `max` (BS-Roformer + MelBand Roformer, результаты усредняются; вдвое дольше) | `high` |
| `--clean-vocals` | дополнительно вокал без эха, реверберации и шума: `<имя>_vocals_clean` (в режиме `backing` — `_lead_clean`) | выкл. |
| `--no-cache` | разделять заново, даже если этот файл уже обрабатывался с теми же настройками | выкл. |

### Расширения

| Параметр | Что делает | Файлы на выходе |
| --- | --- | --- |
| `--mode stems` | 4 дорожки | `_vocals`, `_drums`, `_bass`, `_other` и `_instrumental` из дорожек `--mix` |
| `--mix drums,other` | что смешать в минус в режиме `stems` (`none` — не делать минус) | |
| `--mode backing` | основной голос и бэк-вокал отдельно | `_lead`, `_backing`, `_instrumental`, `_instrumental_backing` |
| `--lyrics` | распознаёт текст по вокалу (Whisper) | `<имя>.txt` и `<имя>.lrc` с таймкодами |
| `--language auto\|ru\|en` | язык текста | |
| `--lyrics-online` | с `--lyrics`: сначала ищет готовый текст с таймкодами в [LRCLIB](https://lrclib.net) по исполнителю, названию и длительности; если не нашёл — распознаёт сам | те же `.txt` и `.lrc` |

Вместо файла можно передать ссылку на трек или видео — звук скачается (yt-dlp) в папку результата как mp3:

```
uv run splitter "https://..." --out ./result --mode backing --lyrics
```

Пресеты — готовые наборы настроек: `--preset vocals` (минус + вокал), `no-drums` (минус без ударных),
`no-bass` (без баса), `backing` (бэк-вокал отдельно). Явные `--mode` и `--mix` важнее пресета.
В окне пресет выбирается списком, свои настройки можно сохранить кнопкой «Сохранить как…».

Готовые дорожки показываются в окне под каждой песней: двойной щелчок открывает файл, правый щелчок —
«Показать в папке», файлы можно перетащить мышью в проводник или другую программу.

«Слушать…» открывает микшер: у каждой дорожки свой ползунок громкости и «выкл.», галочка «Слушать оригинал»
для сравнения, «Сохранить микс» пишет то, что звучит, в `<имя>_mix`. «Текст…» открывает редактор текста со звуком:
строку можно прослушать, сдвинуть на ±0,1 с или поставить время по текущей позиции — если включить песню и нажимать
Enter в начале каждой строки, время расставится заново за одно прослушивание. При поиске готового текста в интернет
уходят только исполнитель, название и длительность; по умолчанию поиск выключен.
Если что-то пошло не так, выберите песню с ошибкой и нажмите «Скопировать отчёт» — получится текст для разработчика
(без путей к вашим папкам). Журналы последних 5 запусков лежат в `%LOCALAPPDATA%\splitter\logs`.

Скачивайте только то, на что у вас есть права. В окне всё то же самое: режим, галочки «Смешать в минус»,
«Распознать текст», кнопка «Добавить ссылку…»; распознанный текст правится кнопкой «Текст…».

В очереди у каждой песни видны обложка, длительность и звуковая волна. В меню «Настройки» — тема (как в системе,
светлая, тёмная), язык интерфейса (русский или английский; по умолчанию — язык системы) и «Скачать модели заранее…»:
мастер проверяет видеокарту и место на диске и скачивает выбранные модели сразу. При первом запуске он открывается сам.

Повторная обработка того же файла (по содержимому, а не по имени) с теми же настройками берёт уже готовые дорожки —
секунды вместо минут; если их удалили или изменили, трек считается заново. Окно запоминает необработанные песни
и при следующем запуске возвращает их в очередь.

Модели скачиваются при первом запуске в `%LOCALAPPDATA%\splitter\models`
(Linux: `~/.cache/splitter/models`), дальше интернет не нужен.

## Сборка приложения

Готовое приложение не требует ни Python, ни uv, ни ffmpeg — всё внутри (PyInstaller, одна папка).

| Платформа | Команда | Результат |
| --- | --- | --- |
| Windows | `powershell -ExecutionPolicy Bypass -File packaging\build_windows.ps1` | `packaging\dist\Splitter\` и установщик `packaging\dist\SplitterSetup-*.exe` с `.bin`-файлами |
| Windows, лёгкая | `powershell -ExecutionPolicy Bypass -File packaging\build_windows_light.ps1` | `packaging\dist-light\Splitter\` и `packaging\dist\SplitterSetup-light-*.exe`: без CUDA, для компьютеров без подходящей NVIDIA (расчёт на процессоре) |
| Linux | `bash packaging/build_linux.sh` | `packaging/dist/Splitter-linux-x86_64.tar.gz` |

В папке приложения два файла: `Splitter` — окно, `splitter-cli` — командная строка (те же параметры, что у `uv run splitter`).
Установщик для Windows собирается [Inno Setup](https://jrsoftware.org/isinfo.php) (`winget install JRSoftware.InnoSetup`),
ставится без прав администратора. Из-за PyTorch с CUDA приложение занимает около 4,5 ГБ, поэтому установщик
разбит на `.exe` и `.bin`-файлы — переносить их нужно вместе.

Модели в сборку не входят: они скачиваются при первом запуске.

Linux (проверено в WSL Ubuntu на RTX 4060): для сборки нужен компилятор C — пакет `diffq` не выкладывает готовую
сборку под Linux (`sudo apt install build-essential`). Для окна нужны библиотеки Qt для X11
(`sudo apt install libxcb-cursor0 libxkbcommon-x11-0`), для прослушивания — `libportaudio2`.
Архив с CUDA весит около 3,9 ГБ — больше лимита GitHub на файл релиза (2 ГБ).

Функций караоке (подсветка слов, видео, тональность и темп) в приложении нет и не планируется.

Окно запускает обработку в отдельном процессе ([worker.py](src/splitter/worker.py)): так интерфейс не подвисает,
а «Отмена» срабатывает сразу. Тесты: `uv run pytest`.
